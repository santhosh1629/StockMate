# StockMate – Inventory Management App

## Project Overview
StockMate is an Android application designed to help
small businesses manage products, inventory, and sales.

## Technologies Used
- Kotlin
- Jetpack Compose
- Firebase Firestore
- Android Studio

## Features
- Product Management
- Stock In and Stock Out
- New Bill Creation
- Sales History
- Dashboard Statistics
- Low Stock Notifications
- Firebase Backend Integration

## Backend Integration
Firebase Firestore is used to store and retrieve
product and sales information.

## Testing
The application features were tested to verify
product management, inventory updates, billing,
sales history, and low-stock notifications.
